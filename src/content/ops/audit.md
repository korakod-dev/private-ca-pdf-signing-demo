## อธิบายสั้น
Audit log คือสมุดบันทึกเหตุการณ์สำคัญของระบบ เช่น ออกใบ เพิกถอน เซ็น ปฏิเสธการเซ็น ลบเอกสารจากคลัง

บันทึกแต่ละบรรทัดผูกกับบรรทัดก่อนหน้าด้วยค่า hash ถ้ามีใครแอบแก้บรรทัดเก่า ค่า hash จะไม่ตรงและจับได้ ปุ่ม "ตรวจ hash chain" คำนวณใหม่ทั้งหมดในเบราว์เซอร์ของคุณ

## รายละเอียดทางเทคนิค
- สูตรใน demo นี้: `hash = SHA-256(hash ก่อนหน้า + บรรทัดใหม่ + ข้อมูลของรายการนี้เรียงคีย์แบบตายตัว)` รายการแรกใช้ค่าเริ่มต้นเป็นเลข 0 จำนวน 64 ตัว
- ตรวจด้วย WebCrypto (`crypto.subtle`) จริง ต่างจากส่วนอื่นของ demo ที่เป็นค่าคงที่
- ถ้าไม่ผ่าน ระบบบอก `seq` ของรายการแรกที่ผิด
- ข้อมูลอยู่ในเบราว์เซอร์ของคุณเท่านั้น ถ้าแก้ข้อมูลใน localStorage เองจะเห็นผลไม่ผ่านทันที
