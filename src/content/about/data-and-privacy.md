เดโมนี้ไม่เก็บข้อมูลของคุณ

- ไม่มี analytics ไม่มี cookie ติดตาม
- ทุกอย่างที่คุณทำเก็บอยู่ใน browser ของคุณเอง กดปุ่ม "รีเซ็ต" ที่แถบสาธิตเพื่อล้างได้
- ไม่มีช่องให้กรอกเลขบัตรประชาชน รูปบัตร หรือ laser code แม้เป็นข้อมูลปลอม
- ไฟล์ที่คุณเลือกอัปโหลดจะไม่ถูกอ่าน และไม่ถูกส่งไปไหน
- ชื่อทั้งหมดในเดโมเป็นชื่อสมมติ ไม่ใช้ชื่อหน่วยงานหรือโลโก้จริง

## รายละเอียดทางเทคนิค
- ข้อมูลสถานะอยู่ใน localStorage ใต้คีย์ที่ขึ้นต้น pcpsd. (ใช้เฉพาะในเครื่องคุณ)
- ความเห็นรับผ่านลิงก์ฟอร์มภายนอกเท่านั้น (ถ้าเปิดรับ) เดโมเองไม่มี server
- ฉบับย่อสำหรับ demo: ยังไม่ได้เทียบกับ spec หลัก (สมมติฐาน A19)
