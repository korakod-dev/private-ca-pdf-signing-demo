ขั้นตอนบน Mac: นำไฟล์ Root เข้า Keychain Access แล้วตั้งให้เชื่อถือ ทำเมื่อเทียบ fingerprint ผ่านแล้วเท่านั้น

## รายละเอียดทางเทคนิค
- การตั้งให้เชื่อถือ คือการเพิ่ม Root เป็นจุดเริ่มต้นความน่าเชื่อถือของเครื่องคุณ ผลกระทบกว้างกว่าไฟล์ PDF
- ภาพทีละขั้นเป็นภาพจำลอง ไม่ใช่ภาพหน้าจอจริง และไม่ใช้โลโก้ของระบบปฏิบัติการ ชื่อเมนูจริงอาจต่างตามเวอร์ชัน
- ฉบับย่อสำหรับ demo: ยังไม่ได้เทียบกับ spec หลัก (สมมติฐาน A19)
